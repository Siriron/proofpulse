# 🛰️ ProofPulse

**Consensus-backed infrastructure incident accountability on GenLayer.**

ProofPulse lets infrastructure providers lock service commitments before claimants open evidence-bound incidents. The protocol supports observations, provider responses, challenges, GenLayer consensus resolution, independent appeals, closure and archival.
